## 数据结构

### 节点类型

1. **persons** - 人物节点（234个）
   - 包含真实历史人物和文学角色
   - 按时代分布：上古→春秋→战国→秦汉→唐宋→明清→近代→现代

2. **events** - 事件节点（41个）
   - 关键历史事件和文学情节事件

3. **concepts** - 概念节点（159个）
   - 核心概念、主题、用户感悟
   - 用户感悟带💡标记

4. **books** - 书籍节点（58个）
   - 记录阅读过的所有书籍

5. **relations** - 关系（237条）
   - 人物间关系
   - 关系必须连接人物节点

### 节点字段

| 字段 | 说明 |
|------|------|
| id | 唯一标识符 |
| name | 名称 |
| type | 节点类型 |
| era | 时代/朝代 |
| description | 描述 |
| source_book | 来源书籍 |
| tags | 标签数组 |

## 使用说明

### 查看知识图谱

1. 打开 `知识树总览.md` 查看人类可读的摘要
2. 查看 `knowledge_base.json` 查看完整数据
3. 用diagrams.net打开 `人物关系图.drawio` 查看可视化图谱
4. 在浏览器中打开 `历史年表.html` 查看交互式时间线

### 更新知识图谱

运行 Python 脚本处理新的读书笔记文件，自动提取人物、事件、概念并更新JSON。
